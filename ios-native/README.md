# Noir for iPhone

Native SwiftUI edition of Noir. The web, Android mobile, and Android TV projects
remain independent from this target.

## Open and run

1. Open `Noir.xcodeproj` in Xcode 27.
2. Select the `Noir` target, then `Signing & Capabilities`.
3. Choose your personal Apple Development team.
4. Connect and trust the iPhone, select it from the run destinations, and Run.

The deployment target is iOS 18. Liquid Glass is applied by the system on iOS 26
and later; older supported releases receive a native Material fallback.
